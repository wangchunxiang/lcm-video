# 样式规范 v3（Tailwind 4 + 令牌）

> 适用范围：`apps/web`（用户端前台）。管理后台 `apps/admin` 用 Element Plus，不适用本文。
>
> 本文替代 [样式规范.md](样式规范.md)（v2，面向手写 CSS 的旧前台）；v2 的容器宽度、导航字号、
> 选中态、卡片比例都已作废，保留该文件只为看历史原因。移动端触控细则仍待单独成文（见「九、已知缺口」）。

目标：同一个视觉问题只有一种写法。出现分歧时以本文为准，不以「哪个页面看着顺眼」为准。

## 一、五条硬规则

1. **颜色、字号、间距、圆角、关键尺寸只从 `styles/tokens.css` 取**，模板里不写裸色值和裸字号。
   需要新值时先加令牌，再引用；不要就地 `text-[#123456]`。
2. **只有两档 hover**（详见第六节）：文字/链接变白，带底或带框的按钮提亮边框 + 文字变白。
   不再出现「这里 hover 变蓝、那里 hover 变白」。
3. **`primary`（蓝）只表示「选中 / 当前 / 主操作」**，不兼职 hover 色。
4. **横向边界只由骨架决定**（第七节）。页面区块内部不用 `padding-left/right`、不用负 `margin` 通栏。
5. **禁止裸数值**：`4px`/`10px`/`14px` 这类直接写死的值一律用最接近的令牌或 Tailwind 刻度；
   确实没有对应刻度时，把理由写在旁边（例如 `pb-14` 只为页脚收尾留白）。

### 禁止的写法（踩过的）

- 用负 `margin` 或 `100vw + 负 margin` 把区块撑出容器（滚动条宽度会让 `100vw` 比可见区大，内容会偏）；
- 同一元素同时用 `margin` 和 `gap` 控制同一方向的间距；
- 用 `padding` 假装外边距；
- 在 `base.css` 之外写「无层」CSS：无层样式优先级高于所有 `@layer`，会静默压掉工具类（见第八节第 1 条）；
- 给 `.vue` 自写 CSS 时改颜色/字号——scoped 样式只用来做工具类做不到的事（滚动条、`::after` 兜底、媒体查询）。

### 间距：只有四档

布局只用下面四个值，**没有 24px 这一级**。12 与 20 只允许出现在按钮、角标等**组件内部**的内边距上，不参与页面节奏。

| 档 | Tailwind | 值 | 用在哪 |
|---|---|---|---|
| S1 | `gap-1` | **4px** | 行内微距：图标与文字、筛选项折行（`gap-y-1`） |
| S2 | `gap-2` | **8px** | 同一组内：筛选行与行、按钮组、角标 |
| S3 | `gap-4` / `pt-4` / `pb-4` | **16px** | **页面顶部（顶栏→内容）**、**区块 ↔ 区块**、区块标题→内容、栅格间距、内容→页脚、分页上间距、表单块之间 |
| S4 | `gap-8` / `pt-8` | **32px** | **首页区块节奏**（区块↔区块）、详情页海报↔信息列 |

两条硬规则：

1. **同一个间距只由一侧提供**，不叠加。区块之间用的是「上一块自带 `pb-4`」，父容器就不要再加 `gap`/`mt`；列表页用的是「父容器 `gap-4`」，`FilterBar` 自己就不带 `mb`。
2. **页面顶部一律 16px**（`pt-4`）；首页区块之间用 `gap-8`（32px）拉开节奏。
3. **微距也走这四档**：图标与文字用 **4**（`gap-1`），并列元素（标题↔副标题、按钮组、指示条之间、logo 图标↔站名）用 **8**（`gap-2`），不再出现 2 / 6 / 10 / 12 / 14 / 40。唯一例外是大块留白（空状态、页脚底部）取 **64 = 2×32**。

> 详情页实测：三个 section 都是 `padding-bottom: 16px` + `margin: 0`，可见间距恒定 16px。

### 控件内部：只用 4 / 8 / 16

页面节奏管到「块」，块内部的按钮、角标、面板另有一套固定值，同样不许出现 12 / 20 / 24 / 28。

| 控件 | 高度 | 水平内边距 | 备注 |
|---|---|---|---|
| 主 / 次按钮（立即播放、浏览分类、加载更多、回到首页） | `h-[38px]` | **`px-4`(16)** | 主次只靠填充色与描边区分，不再靠宽度差 |
| 分页按钮 | `h-[34px] min-w-[34px]` | `px-2`(8) 且居中 | 方形，宽度由 `min-w` 保证 |
| 小控件（线路行、选集行、标签切换） | `h-8`(32) 或 `h-[30px]` | **`px-4`(16)** | 高度固定，**不再用 `py-*` 撑** |
| 角标 / chip（海报角标、年份/分类标签） | 由文字行高决定 | **`px-2`(8) `py-1`(4)** | 四角 `rounded-sm` / `rounded` |
| 输入框 / 搜索胶囊 | `h-9`(36) 或 `h-full` | **`px-4`(16)** | 容器负责内边距，内部 `input` 不再重复加 |
| 抽屉面板（Sheet） | — | **`px-4 py-4`** | 头 / 身 / 脚三处一致 |
| 页脚 | — | `py-8 pb-16`（32 / 64） | 底部留白取 2×32 |
| 空状态 / 加载态占位 | — | `py-16`（64）或 `py-8`（32） | 大块占位取 2×32 |

改控件尺寸时先看这张表，不要就地写 `px-5`、`py-2.5`、`py-[7px]`。

### 布局与尺寸

| 令牌 | 值 | 说明 |
|---|---|---|
| `--container` | 1600px | 内容区最大宽 |
| `--container-gap` | 96px | 两侧留白（≥768px 时生效） |
| `--header-h` | 56px | 顶栏高度；实际占位 +1px 边框 |
| `rounded-sm` / `rounded-md` / `rounded-lg` / `rounded-pill` | 4 / 8 / 12 / 999px | 圆角：`--radius-sm`、`--radius`、`--radius-lg`、`--radius-pill`（映射见 `styles/tailwind.css`） |

## 三、页面骨架

```
App.vue
├─ SiteHeader   顶部：品牌 + 一级分类导航 + 搜索；sticky，高 56px(+1px 边框)
├─ <main>       内容区：默认由 Container 收边；pb-6
└─ SiteFooter   底部：免责声明 ←→ 版权
```

- **顶栏**：`sticky`（在流里占位，不浮在内容上）。底色恒定 `rgba(10,12,15,.55)` + `backdrop-blur-xl` + `border-line/70`，
  滚动前后一致；不写「顶部透明、滚动变实」的切换。
- **内容区边界**：`Container.vue`（`.page-container`）唯一来源，`min(--container, 100% - --container-gap)`，
  手机 `100% - 28px`。页面里不再出现第二套宽度。
- **通栏页面**：路由 `meta.fullBleed: true`（首页、详情页）。这类页面自己拿满宽度，其余区块自己再套 `Container`。
  新页面需要大图 / 虚化横幅通栏时照此办理，**不要用负 margin**。
- **上下留白归页面**：`<main>` 只给 `pb-4`；每个页面根节点自己给 `pt-4`（详情页的 `pt-4` 在横幅内部，横幅自己贴着顶栏）。
  顶栏高度由 `sticky` 自然占位，页面不要再补 `padding-top`。

## 四、栅格与列表

| 场景 | 列数 | 说明 |
|---|---|---|
| 海报网格 `VodGrid` | 2 / 3 / 4 / 6 列（`sm/md/lg`），≥1400px 8 列 | 列间距 `gap-4` |
| 首页区块 `VodSection` | 8 列 × 2 行（≥1400px 每行 8 部，共 16 部） | 列数沿用 `VodGrid` 断点，窄屏自动折行 |
| 详情页 | 左海报 200–236px + 右内容 | `max-lg` 单列 |
| 播放页 | 播放器 + 右侧 296–380px 选集栏 | `max-lg` 单列 |

海报比例统一 **2:3**（`aspect-[2/3]`，= 0.667）。这是定稿值，别再按「封面实测中位数」去调——库里 80 张封面的比例很杂
（0.56 到 1.54），而 `VodCard` 用 `object-fill` 拉伸填充，框固定 2:3 才能让所有卡片一致。列表页每页条数取 `site.config.listPageSize`（默认 24）。

## 五、组件契约

| 组件 | 约定 |
|---|---|
| `Container` | 只负责宽度与居中；不设上下留白 |
| `SiteHeader` | 高 `--header-h`；三段（品牌 / 导航 / 搜索）之间与导航项之间统一 **`gap-8`(32px)**；导航只放一级分类（图标 16px + 文字 14.5px）；搜索为胶囊 230×36 |
| `SiteFooter` | `py-7 pb-14`、`text-caption text-ink-3`，左右两段 flex 撑开 |
| `VodCard` | 海报 **2:3**、图片**拉伸填充**（`object-fill`，不裁剪）、角标右上（备注/集数）、**hover 不上移、不出现播放图标**：只加 `ring-primary-line` 描边 + 内部图片放大 **1.14**（500ms）；卡片下方只有**一行片名** `text-vod`（不放年份 / 地区副标题） |
| `VodSection` | 区块 = 标题 `text-section` + 副标题 `text-small` + 右侧「更多」+ `VodGrid`；「更多」为 `text-emphasis`(15px) + `chevron-right` 图标 16px，hover 只变白、图标不动（用 `>` 形状的 chevron，不用 `>` 字符、不用长箭头、不做位移）；默认最多 16 部（8 列 × 2 行） |
| `DetailView` 横幅 | 详情页是 `meta.fullBleed` 页面：顶部横幅通栏，前景内容收进 `Container`。横幅 = 封面 `bg-cover` + `scale-110` + `blur-2xl`（手机 `blur-lg`）+ 一层 `linear-gradient(180deg, .55 → .72@55% → var(--bg))`，两层都 `pointer-events-none`；**`overflow-hidden` 只挂在背景层上**，section 本身 `relative isolate z-10` 不裁剪，否则简介浮层会被横幅底边裁掉。海报 **`aspect-[2/3]` + `self-start`**（不加 `self-start` 会被 flex `stretch` 撑高）。**简介摘要 2 行**：离屏探针 + 二分实测截断（不是按字数估算），并**在末尾预留 2 个字宽**，避免「详情」顶到内容区右边界；按钮 14px 强调色紧跟省略号；点开是**居中弹窗**（`Teleport` 到 body，宽 `min(640px, 100% - 48px)`、`max-h-[70vh]`、`bg-surface` + `shadow-pop`，背后 `bg-scrim` 遮罩），关闭方式＝「关闭」按钮 / 点遮罩 / Esc；打开时锁滚动并补回滚动条宽度，页面不位移。不做抽屉、不做原位浮层 |
| `DetailView` 线路 / 选集 | 线路是**下划线标签页**：外层 `-mb-px` 压住整行的 1px 分隔线、`overflow-x-auto` 横滑且隐藏滚动条、`gap-4 sm:gap-8`，整行 `flex items-end gap-4 border-b border-line`；每个按钮 `pb-2 pt-2 text-body`（行高 38），选中 `text-primary` + **`shadow-[inset_0_-2px_0_var(--color-primary)]`**（不用 `border-b-2` + 负 margin，否则下划线会和分隔线错位或被子元素 overflow 裁掉），未选中 `text-ink-2 hover:text-ink`。**前台不做无障碍**（个人站）：不写 `role` / `aria-*`，也不用 `sr-only` 的标题。行尾是**正序 / 倒序**开关：纯文字 `text-small`、`ink-3` 且 hover 变白、**文案就是当前状态**（`正序` / `倒序`）、不用 `primary`（它不是选中态）；偏好存 `localStorage['lcm:ep-order']`（`desc` = 最新集在前），倒序**只反转渲染顺序**，`ep.index` 与高亮不变，「立即播放」永远指向第 1 集。选集网格 4 / 6 / 8 / 10 列；格子高 `--ep-cell-h`(30px)、行距 `--ep-gap`(8px)、`text-caption`、单行省略号 + `title` 全名；容器 `max-h-[var(--ep-max-h)]` = **整 10 行（372px）**，不用 420 这种半行高度，底部不会露出被切一半的格子；集数不够 10 行时高度就是内容高度，不出现滚动条 |
| `FilterBar` | 行式**纯文字**筛选（不做按钮/胶囊/底色），只有「类型 / 年份 / 排序」三行——**一级分类不在这里切，顶栏导航已经有了**；层级靠字号分：**行标签 13px（`text-small`）`ink-3`、固定宽 32px** ＜ **条目 14px（`text-body`）`leading-6`** ＜ 片名 16px；选中 `text-primary`、未选中 `text-ink-2 hover:text-ink`；行内 `gap-x-4`(16px)、行间 `gap-y-1`(4px)，`items-baseline`；某一行没数据（如「全部」以外的分类无子类型）就整行不渲染。列表页**没有标题行、没有侧栏、没有「全部影片」聚合页**；也不放 `sr-only` 的 `h1`（前台不做无障碍，见 `DetailView` 线路那条） |
| `PaginationBar` | 34px 方形按钮；当前页实心 primary；hover 提亮边框；页码窗口**固定 5 个**，最后几页向前对齐（否则点「尾页」后只剩 3 个）；`page` 超出实际页数（手工改 URL、或采集后总量变少）由页面自动纠正到最后一页，避免空页时连分页条都没有 |
| `ui/Skeleton` | `animate-pulse bg-surface-2`，高度与真实内容一致，避免填充时跳版 |
| `ui/GridSkeleton` | 标题条 + 8 列 × 2 行海报骨架，列数与 `VodGrid` 一致（≥1400px 也是 8 列），填充时不跳版 |
| `ui/Sheet` | 移动端抽屉；关闭按钮 hover 为 `bg-surface-2` |
| 图标 | **直接用 `lucide-vue-next` 的组件**（按需引入、`sideEffects:false`，只打用到的图标），**不套封装、不做名字映射**：模板里写 `<ChevronRight :size="16" class="shrink-0" />`。形状与描边全部用 lucide 默认值（`stroke-width: 2`），**不要**再传 `stroke-width`；只传 `:size`（14 / 16 / 20）和必要的 `shrink-0`；颜色跟随 `currentColor`；动态列表需要图标时用「alias → 组件」的小映射（见 `SiteHeader` 的 `CATEGORY_ICONS`），不要按中文名猜 |

封面兜底：统一用 `/img/poster-placeholder.svg`——**画布就是 2:3（300×450）且带 `preserveAspectRatio="none"`**，塞进任何比例的框都是拉伸铺满、不留透明边；图片 `onerror` 时切到它，容器再垫一层深色渐变过渡。不要用 `content:attr()` 文字兜底。

## 六、交互状态

### hover 只有两档

| 类型 | 写法 | 用在哪 |
|---|---|---|
| 文字 / 链接 / 芯片 | `text-ink-2 transition hover:text-ink` | 导航、`更多 ›`、筛选芯片、页脚链接、404 分类 |
| 带底或带框的按钮 | `hover:border-ink-3/50 hover:text-ink`（有底的再加 `hover:bg-surface-3`） | 分页、加载更多、线路切换、选集格 |
| 纯图标按钮 | `hover:bg-surface-2 hover:text-ink`（36px 方形 + `rounded-md`） | 移动端搜索/菜单、抽屉关闭 |

特例（不算分档，各有明确原因）：
- 实心主按钮 hover 换底色：`bg-primary hover:bg-primary-strong`；
- 海报卡 hover 是「上浮 + 描边 + 播放浮层」，片名**不变色**；
- 搜索胶囊 hover 提亮边框、`focus-within` 时边框转 `primary-line`。

### 其它状态

| 状态 | 表现 |
|---|---|
| 选中 / 当前 | `text-primary`；需要块状指示时用 `bg-primary-weak`（导航、线路）或 `bg-primary text-white`（页签、当前集） |
| 禁用 | `text-line` + `cursor-not-allowed`（按钮重置已在 base 层给 `:disabled` 兜底） |
| 加载 | 骨架块，绝不写「加载中…」文字占位 |
| 错误 | `text-danger`，居中一行，不弹 toast（前台没有全局提示层） |

## 七、已踩过的坑（别再踩）

1. **CSS 层叠**：`base.css` 必须整份包在 `@layer base {}` 里。无层样式优先级高于所有 `@layer`，
   否则 `a{color:inherit}` 会静默压掉 `text-*`，表现为「链接颜色怎么写都不生效」。
   层级顺序在 `styles/tailwind.css` 开头声明：`theme → base → components → utilities`。
2. **没引 Tailwind preflight**（刻意，为了不重置标题/表单默认样式），所以 `<button>` 的浏览器默认底色
   （`color-scheme:dark` 下是 `#6b6b6b` 灰块）和边框要自己在 base 层清掉，否则按钮看着脏、hover 也不对。
3. **顶栏别用 `fixed`**：`fixed` 会让首屏大图跑到顶栏背后，滚动态与静态两种观感不一致；
   用 `sticky`，并在流里占位。
4. **列表接口 `sort=new`** 走 `v.created_at`（无索引），12 万行要 9–16 秒；默认排序走 `collected_at`（有索引）。
   首页区块一律不传 `sort`。
5. **分类列表接口本身就要 2–5 秒**（每次 5 条 SQL：分类、子分类、列表、`COUNT`、`DISTINCT year`）。
   首页因此逐行加载：「今日更新」先出，四个分类行谁回来填谁，骨架占位。
6. **图标用 `currentColor`**：给图标上色改父级文字色，不要另加 `fill`。
7. **令牌重复**：改 `--ep-max-h` 这类值时先 `grep` 全文，避免出现两条同名声明互相覆盖。

## 九、已知缺口（有意留白，别当成规范）

- **键盘焦点**：除搜索框的 `focus-within` 外，还没有统一的 `focus-visible` 描边；输入框用了 `outline-none`，
  键盘用户目前看不到焦点。补的时候统一走 `ring-1 ring-primary-line`。
- **移动端**：目前是同源响应式（断点 640 / 768 / 1024 / 1400），没有 v2 那种独立移动模板；
  触控尺寸（最小 44px）与安全区尚未成文。
- **详情/播放页**：仍是旧结构，只做了 hover 与骨架统一，尚未按 D1 重做（线路表、选集区）。
- **数据缺口**：库里没有评分、播放量、热度字段，任何方案都不要凭空造这三个数字。
