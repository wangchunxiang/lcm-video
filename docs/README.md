# 文档索引

本目录只留**现行有效**的决策文档与规范，共 3 份；过时的盘点与本轮开发的过程记录都已删除，不再维护。

> 命名约定：文档标题里的 `v2` / `v3` 指**架构的大版本**，不是文档版本。
> 现状是：服务端、数据库按「架构 v2」落地，前端（后台 + Web 前台）按「v3」落地。新文档不要再带版本号。

## 阅读顺序

| 目录 | 文档 | 内容 | 什么时候读 |

## 权威性

冲突时按这个顺序取：**代码 > 样式规范 > 架构总览 > 数据库设计**。

- `架构总览` 与 `数据库设计` 已对齐现行 TypeORM 实现；两者若与实体/源码不一致，以代码为准并顺手修文档。
- 后台（`apps/admin`）用 Element Plus，不适用 `样式规范.md`。
