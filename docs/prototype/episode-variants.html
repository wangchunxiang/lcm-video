剧集区排版方案

同一份真实数据渲染成 8 种排版：Running Man / 如意资源 107 集（含 E721.240929 这类混合命名），长番用「电影天堂 829 集」演示。当前线上是 V1。拉动浏览器宽度可以看到各自的响应式表现。

V1 现状：按文字宽度换行，省空间但不整齐
V2 紧凑等宽：列等宽、列数自适应，视觉最整齐
V3 年份折叠：按年份分组，适合几百上千集
V4 分段分页：每 100 集一段，长番不刷屏
V5 双行标签：上行日期、下行集号，信息最清楚
V6 两列列表：像目录，适合集数多、名字长的片
V7 数字圆点：只有集号，适合番剧
V8 横向条：单行横滑 + 跳集，播放页侧栏用

V1 · 现状：自适应宽度

线上正在用

标签宽度 = 文字宽度 + 12px 内边距，一行排满自动换行。省空间，但长短名字混排时右边缘参差，很难一眼扫到某一集。

1100px 宽约一行 11 个。

V2 · 紧凑等宽

推荐试

网格等宽、列数随宽度自适应（78px 起），名字过长省略号截断、悬停看全名。整齐度最高，代价是长名字默认看不全。

1100px 宽约一行 12 个，与 V1 数量接近但边缘对齐。

V3 · 年份分组 + 折叠

长番首选

按年份分组，每组一行标题（年份 + 数量），可点开收起，默认只展开最近一年。几百集也不刷屏；代价是多一次点击。

用「电影天堂 829 集」的数据演示（2010–2026）。

V4 · 纯分页（每页 50）

按你的方向改

去掉 100 集分段，直接按每页条数翻页：上方显示总集数与每页条数切换，下方是页码 + 跳转。结构最简单，规则统一；集数越多翻页次数越多。

共 829 集

每页条数可切换（30 / 50 / 100），默认 50。

V5 · 双行标签

信息最清楚

上行放日期（统一成 09-29），下行放集号或原始前缀（E721）。解决混合命名，一眼看出是哪一期；代价是高度从 28px 涨到 42px。

E721.240929 拆成 09-29 + E721，纯日期的显示「第 N 期」。

V6 · 两列列表

备选

像目录：序号 + 名称，两列并排。名字再长也不会挤，适合集数多、命名长的片；视觉上比标签重，占高度。

V7 · 数字圆点

番剧向

只显示集号（01、02…），圆形等宽，一行放很多。动漫、短剧最合适；综艺这种日期命名会丢信息，只建议番剧页单独启用。

用 120 集番剧演示。

V8 · 横向条 + 跳集

播放页侧栏

只占一行，左右滑动，右侧带跳集输入框，当前集自动滚到可视区。不挤压简介和推荐位；不适合详情页做主入口。
