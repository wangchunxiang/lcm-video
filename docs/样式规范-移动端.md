# 移动端样式规范

移动端是独立模板（`themes/default/mobile/`）与独立样式（`themes/default/assets/mobile.css`），
不是桌面布局的响应式缩放。本文只约束移动端；颜色、间距刻度与桌面共用，
容器、触控尺寸、安全区按本文执行。桌面规范见 [样式规范.md](样式规范.md)。

## 1. 横向边界

- 正文统一放在 `.m-main` 内，左右各留 `var(--pad)`（16px）。
- 需要贴边通栏的内容（播放器、吸顶筛选条、搜索条、横滑分类）**只能放在模板的
  `{% block top %}` 里**，它位于 `.m-main` 之外，天然满宽。
- 禁止用负 margin、`100vw`、`margin-left: 50%` 等方式让元素“撑破”父级。
- 卡片、面板不做整行贴边；标题与卡片左边缘对齐。

## 2. 间距

- 只允许 4 的倍数：`--space-1..7` = 4 / 8 / 12 / 16 / 20 / 24 / 32。
- 区块之间用 `.m-sec` 的 `margin-top: var(--gap-block)`（24px），首块贴住顶部留 16px。
- 同一容器内的元素间距用父级 `gap`，不要再给子元素加同方向 margin。
- 卡片内边距用 `--pad-card`（12px）或 16px；整页边距用 `--pad`（16px）。
- 不要用 padding 假装外边距，也不要把 margin 写进组件内部。

## 3. 触控

- 主要操作（按钮、上下集、播放）高度不小于 `--tap`（44px）。
- 胶囊、筛选 chip 高度不小于 38px；剧集格子高度 44px、最小宽度 56px。
- 相邻可点区域之间至少留 8px，避免误触。
- 所有图标按钮必须有可读的 `aria-label`，不依赖颜色表达选中状态
  （选中态同时用底色 + 字重 + `is-on` 类）。

## 4. 字体与层级

- 正文 15px / 1.6，次要信息 13px，辅助信息 12px；不出现 10px 以下文字。
- 页面标题 20px / 700，区块标题 16px / 700，卡片标题 14px / 600。
- 标题最多两行，超出用 `-webkit-line-clamp` 截断；不要用 `nowrap` 撑破布局。
- 数字、集数使用等宽感排版（`font-variant-numeric: tabular-nums`）避免跳动。

## 5. 图片与媒体

- 海报统一 2:3，`object-fit: cover`，圆角 `--radius`（12px）；禁止 `object-fit: fill`。
- 列表缩略图 3:4（72×96），同样 `cover`。
- 播放器 16:9，黑色底；播放器区域由 `{% block top %}` 承载，不参与正文 padding。
- 图片必须有 `alt`（装饰图写空 `alt=""`），并使用懒加载与占位背景色。

## 6. 安全区

- 顶栏高度 `calc(var(--header-h) + env(safe-area-inset-top))`，内容下移 `--safe-top`。
- 吸顶元素（筛选条、搜索条）的 `top` 与顶栏高度一致。
- 底部抽屉、页脚、悬浮操作区补 `env(safe-area-inset-bottom)`。
- `viewport` 使用 `viewport-fit=cover`，页面背景延伸到刘海区域。

## 7. 组件约定

- 前缀统一 `m-`，块名 + 元素名：`.m-card` / `.m-card-cover` / `.m-card-title`。
- 状态类只用 `is-on`、`is-active`、`is-off`、`is-loading`、`is-scrolled`。
- 抽屉统一用 `.m-sheet` + `data-sheet` / `data-sheet-open` / `data-sheet-close`，
  由 `mobile.js` 统一管理开合、遮罩、Esc 与页面滚动锁。
- 剧集网格保留 `.m-ep-grid` / `.m-ep`，线路胶囊保留 `.m-pill[data-ep-line]`，
  播放页副标题 `.m-play-sub`、抽屉计数 `.m-sheet-count`、操作区 `.m-play-actions`
  由 `app.js` 就地换集时同步，不要改名。

## 8. 禁止清单

- 负 margin、`100vw`、整行 `padding` 模拟外边距。
- 在模板里写内联 `style`（由 `--space-*` / 组件类承担）。
- 裸色值、裸字号、裸圆角（统一用 `:root` 令牌）。
- 小于 44px 的主要操作、小于 12px 的正文字号。
- 在移动端模板里复用桌面类名（`.container`、`.detail-banner`、`.player-box` 等）。
