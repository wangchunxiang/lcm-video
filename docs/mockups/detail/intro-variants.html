详情页 · 简介的 6 种展现形式

同一份数据（597 字简介）＋ 当前生产样式还原。每块都能点：A 浮层 / B 弹窗 / C 底部抽屉（手机）/ D 页内展开 / E 整宽区块锚点 / F Tab 分栏。

A原位浮层（当前线上）

点「详情」→ 盖在简介格上，玻璃底、最高 240px、内部滚动；关闭＝按钮/点外部/Esc。

B居中弹窗

点「详情」→ 640px 居中卡片 + 遮罩，阅读宽度最舒服；关闭＝按钮/遮罩/Esc。

C底部抽屉（手机形态）

手机上从底部滑出 85% 高的抽屉，手势自然；桌面端不推荐（占半屏）。

· 抽屉圆角 16px、顶部一条分隔线
· 内容区独立滚动，页面本身不滚动
· 关闭：下滑 / 点遮罩 / 关闭按钮

D页内展开（行内长高）

点「详情」→ 简介在原位展开，按钮与线路整体下移；零额外层级，但首屏会变长。

E整宽区块 + 锚点跳转

点「详情」→ 平滑滚到下方整宽的「详细介绍」区块（它自己最高 200px 内滚动）。

FTab 分栏（简介 / 剧集）

简介与剧集拆成两个 Tab，页面最干净；属于详情页整体重做的范围。
