我的取舍：B 或 C。理由——hero 的目的是「一进来就能播」，把它当一个动作处理；「查看详情」和点击标题/海报是同一个目的地， 并列成两个按钮会让首屏出现两个同等重要的选择。B 适合保留一点解释（那行小字），C 适合完全不解释、把信息压到最少。
D 的问题是元信息在片名前，第一次看会觉得「先看到一串小字再看到片名」，但在有明确题材偏好时更好用。E 更戏剧化，但居中排版会和左对齐的 rail 打架。
