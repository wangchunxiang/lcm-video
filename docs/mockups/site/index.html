前台整站 · 四个方向

每套都是完整的四个页面（首页 / 列表 / 详情 / 播放），不是只改首页。全部用本站真实数据与真实封面：今日更新 12 部、在库 124,591 部、详情页是《玫瑰战争国语》的真实线路与 16 集选集。

打开任一方案后，用页面里的「首页 / 列表 / 详情 / 播放」切换看四个视图；右下角有方案徽标，左下角可以回到本页。

D1 · 深夜影院

深色 · 蓝 · 电影感
全幅 hero 轮播撑着首屏氛围，横向 rail 追内容，详情页用模糊剧照做 banner，播放页走沉浸式暗场。
适合 想让站点看起来像流媒体平台 · 视觉冲击优先
  • hero 轮播
  • 横向 rail
  • 详情 banner
  • 沉浸播放页

D2 · 纸感目录

浅色 · 米白 · 衬线
报头＋日期线＋三栏版式，列表页是一张真正可扫读的目录表（缩略图/片名/分类/年份/地区/状态），详情页首字下沉、线路表格化。
适合 白天也好看、想靠文字信息取胜 · 与常见深色采集站完全不同
  • 三栏版面
  • 目录表
  • 线路表 + 首字下沉
  • 浅色播放页

D3 · 信息港

深色 · 青绿 · 高密度
筛选条 + 6 列网格 + 右侧榜单侧栏，一屏能扫到几十部；详情与播放都围绕「找片快、切集快」组织。
适合 片库大、用户目标明确 · 功能与效率优先
  • 筛选 chips
  • 侧栏榜单
  • 路线 + 选集
  • 播放器 + 选集网格

D4 · 海报墙

近黑 · 琥珀 · 画廊
没有 hero、没有侧栏、没有筛选面板，整站就是海报：信息藏在 hover 与详情页里，安静、克制。
适合 想摆脱「采集站」既视感 · 美感与差异化优先
  • 纯海报墙
  • hover 出信息
  • 全屏模糊底 + 居中卡片
  • 极简播放页
对比时建议只看三件事：
① 首屏第一眼能不能看出「这个站有什么、今天更新了什么」；
② 从首页到能点播放，几次点击、有没有走错路；
③ 列表页在 124,591 部这个量级下，你愿不愿意用它找片。

四套都不含评分 / 播放量 / 热度这些库里没有的字段，避免上线时变成假数据。选定方向后我落成 Vue 组件（沿用 tokens.css 与 docs/样式规范.md），需要新接口的地方会先列出来。
