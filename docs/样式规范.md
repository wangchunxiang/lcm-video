# 样式规范：间距与布局

> 移动端是独立模板与独立样式，横向容器、触控尺寸与安全区不适用本文，
> 见 [样式规范-移动端.md](样式规范-移动端.md)。颜色与间距刻度两者共用。

目标：同一类问题只用一种写法，避免「有的用 padding、有的用 margin」导致对齐错位。
## 一、四条基本规则

1. **横向位置只由容器决定**
   页面内容左右边界由 `.container` 统一控制（宽 `min(1800px, 100% - 120px)`，两侧各 60px）。
   页面区块内部不再用 `padding-left/right` 或负 `margin` 制造水平缩进。

2. **元素之间的间距用父级的 `gap`**
   flex / grid 布局中，子元素之间一律用父级的 `gap`，子元素自身不加 `margin-top/left` 之类。
   卡片内多个块（标题、标签、字段、按钮）也优先用 `display: flex; flex-direction: column; gap`。

3. **有背景的才叫卡片，卡片内部留白用 `padding`**
   卡片统一 `padding: var(--pad-card)`（20px），卡片里的子元素不再额外加水平 `padding`。
   需要与正文左右严格对齐的区块，不要做成卡片：直接作为普通区块放在容器里（背景与页面同色、不加左右 `padding`），这样规则里就不需要例外。

4. **区块之间的垂直间距用 `margin-bottom: var(--gap-block)`**
   只加在块级容器上（`.section`、`.detail-banner` 这类），不使用 `margin-top` 做「上一块推下一块」。

## 二、可用的间距刻度

| 变量 | 值 | 用途 |
|---|---|---|
| `--space-1` | 4px | 图标与文字、极小间隙 |
| `--space-2` | 8px | 行内元素之间 |
| `--space-3` | 12px | 紧凑列表 |
| `--space-4` / `--gap-block` | 16px | 区块之间、栅格间距 |
| `--space-5` / `--pad-card` | 20px | 卡片内边距 |
| `--space-6` | 24px | 大区块 |
| `--space-7` | 32px | 页面级留白 |

禁止在样式里直接写 `4px`、`10px` 这类裸数值；确有必要时用最接近的变量。

## 三、禁止的写法

- 用 `margin: auto` 做水平居中（容器已经承担居中，改用 flex/容器）；
- 用负 `margin`（或 `100vw` + 负 margin）把元素撑出容器做成通栏。滚动条宽度会让 `100vw` 比可见区域大，内容会偏移，我们在详情页横幅上踩过这个坑。真要通栏，把区块放到容器外，或用 grid 跨列；
- 同一元素同时用 `margin` 和 `gap` 控制同一方向的间距；
- 用 `padding` 假装外边距（如 `padding-top: 40px` 只为了把下一个块推下去）。
